# HomeFit 서울 — 캡스톤 결과 소개 (캡처·안내문 작성용)

> 이 문서는 다른 세션이 화면 캡처와 안내문을 만들 때 쓰는 기준 자료입니다. 숫자는 2026-11-17 데이터 기준입니다.
> 접속: `…/proxy/8765/` (주소 끝의 `/` 필수). 공유 전에 해당 주소에 접근 제한(로그인)이 걸려 있는지 확인하세요.

## 한 줄 소개
마이데이터 기반 고객 재무 정보와 서울 아파트 실거래 데이터를 결합해, 고객이 **실제로 살 수 있는 예산**을 계산하고 **예산 안의 아파트 단지**를 추천하는 서비스입니다. 다른 사용자와 좋아요를 실시간으로 공유하고, 지금 뜨는 단지를 함께 볼 수 있습니다.

## 핵심 기능 (화면 순서)

## 3분 데모 시나리오
1. 데모 칩 **'전세 세입자 · C0698'** → 기본 조건 예산 약 7,200만원, 후보 0곳(목표 계획 표시).
2. 2단계에서 **생애최초** 선택 + **전세보증금 순반환 반영** 체크 → 예산 **약 3억 8,600만원**, 동네 19곳·아파트 62곳으로 늘고 자치구 타일에 **▲새로**.
3. 4단계 **🏢 아파트 추천** 1~3위 카드 → **📈 시세 등락**으로 동네 추이와 다른 단지 확인.
4. 마음에 드는 단지에 **♥** → 오른쪽 아래 **🔥 인기 급상승**에 실시간 반영(다른 창에서도 확인).
5. 헤더 **📜 부동산 정책 히스토리** → 이 예산이 어떤 규칙(LTV 70%, 스트레스 금리 +3%p, 6억 상한)으로 나왔는지.

다른 예: 사회초년생 **C0343** + 생애최초 + 추가 자금 **+2억** → 예산 약 4억 3,800만원, 아파트 109곳.

## 남아 있는 한계 (안내문에 그대로 써도 됨)
- 실제 매물이 아니라 **신고된 실거래 통계**입니다. 매물 가격은 따로 확인해야 합니다.
- 보유 주택 여부는 **대출 내역으로 추정**하고, 연소득은 급여 입금액이며 **세전·세후 구분이 없습니다**.
- 대출·세금 기준은 **2026년 6월까지 발표된 정책**을 반영했습니다.
- 데이터는 2025.08~2026.11 계약분이며, 2026.10~11월은 신고 기한이 남아 바뀔 수 있습니다. 거래가 많은 일부 구(송파·강서·노원·구로·은평)의 2026년 초 몇 달은 조회 도구 한도로 받지 못해 화면에 '조회 한도로 받지 못한 달'로 표시합니다.
- 가명 고객 데이터는 합성 데이터라 자산 규모가 작습니다. 기본 조건에서는 후보가 거의 없고, 생애최초·전세보증금·추가 자금 조건에서 후보가 나옵니다.

## 데이터와 기술 구성
- **데이터:** 서울 열린데이터광장 부동산 실거래가 정보(seoul-realestate MCP `search_trades`로만 수집), 2025.08~2026.11 계약분 약 14.8만 건(아파트 유효 거래 약 7.5만 건, 단지 약 1,500곳) / 가명 고객 1,000명
- **개인정보:** 지번(본번·부번)은 저장하지 않음. 단지명은 아파트 추천에서만 사용(사용자 승인). 거래 5건 미만·단지 1곳뿐인 동네 시세와 거래 1건뿐인 단지는 비공개
- **구성:** 파이썬 표준 라이브러리 웹 서버 + 단일 HTML(외부 CDN 없음) + Valkey(좋아요·급상승, 실시간 SSE) + S3 백업(버전 관리)
- **검증:** 손으로 옮겨 적은 데이터는 독립 사본·단지 해시로 대조, 코드는 다관점 리뷰와 반박 검증(결함 19건 수정), UI/UX 심층 점검(41건 확인)
