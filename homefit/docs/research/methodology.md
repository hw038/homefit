## 1. 정제와 이상거래 제외 규칙 (지표 계산보다 먼저)

### 1.1 순서
```
def clean(rows):
    # (a) 형식
    drop if amt<=0 or area<=0 or area<10 or area>300 or BLDG_USG!='아파트'
    # (b) 완전 중복 행 (API 페이지 겹침 등): 하나만 남김
    key = (cid, CTRT_DAY, amt, area, FLR, DCLR_SE, RTRCN_DAY or '')
    # (c) 해제: 가격 통계에서는 빼고, 비율 계산용으로 따로 모음
    cancel_pool.append(r) if canceled ; continue
    # (d) 해제 후 재거래 의심 (가격 띄우기 패턴)
    #     해제된 행 c 와 같은 cid, |area-c.area|<=0.5, 같은 FLR 이고
    #     c.CTRT_DAY 이후 90일 안에 맺은 유효 거래 v 가 있으며 v.amt >= c.amt 이면
    #     flag v 'relist_after_cancel' -> 가격 중앙값과 전년비 매칭에서 제외
    # (e) 동일단지 단기 반복거래
    #     같은 (cid, atype, FLR) 유효 거래가 90일 안에 2건 이상이면 가장 이른 1건만 남기고
    #     나머지는 flag 'repeat_90d' -> 제외 (자전거래, 지분 정리 의심)
    # (f) 직거래 저가
    ref = ref_ppm(r)   # 1.2 참고
    if direct and ref and r.ppm < 0.70*ref: flag 'direct_low' -> 제외
    # (g) 극단값 (중개 포함 전체)
    #     셀(구,동,band, 기간 R 또는 P0) 안에서 z = (ln ppm - median(ln ppm)) / (1.4826*MAD)
    #     셀 n>=8 이고 |z|>3.5 이면 flag 'outlier' -> 제외. MAD=0 이면 건너뜀
    return valid, cancel_pool, flagged, excluded_counts
```

### 1.2 기준 단가 ref_ppm(r): 직거래 저가 판정용, 위에서부터 첫 성공을 사용
1. 같은 (cid, atype)의 중개거래 중 계약일 ±180일 안의 거래가 3건 이상이면 그 ppm 중앙값을 씁니다.
2. 같은 (구, 동, band, age_cls)의 중개거래 중 같은 기간(P0 또는 R)의 거래가 5건 이상이면 그 중앙값을 씁니다.
3. 같은 (구, 동, band)의 중개거래가 5건 이상이면 그 중앙값을 씁니다.
4. 셋 다 안 되면 판정하지 않습니다(None). 직거래는 남기되 'direct_unverified' 플래그를 답니다.

가격 기본값은 '판정 통과한 직거래 포함'입니다. 대안으로 직거래를 가격 통계에서 전부 빼는 옵션(PRICE_EXCLUDE_DIRECT=True)도 둡니다.

### 1.3 제외 내역 출력

- 개별 이상 거래를 보여줄 때는 구, 법정동, 면적대, 계약월, 금액대까지만 적습니다. 본번, 부번, 건물명, cid 는 쓰지 않습니다.

## 2. 지표 계산식 (셀 = 구 × 법정동 × band)

### 2.1 ㎡당 가격 중앙값과 분산
```
V_R  = 셀의 기간 R 유효 거래, V_P0, V_P1 도 같은 방식
ppm_med   = median(ppm | V_R)              # 원 단가
ppm_p25/75= quantile(ppm | V_R, .25/.75)  # 선형보간(type 7)
disp      = (ppm_p75 - ppm_p25) / ppm_med # 상대 IQR, 낮을수록 시세가 균질
n_cid     = 셀 V_R 안의 서로 다른 cid 수
dominance = (가장 많은 cid 의 거래 수) / n_R   # > 0.6 이면 '단일 단지 비중 큼' 경고
```
공개 조건은 n_R ≥ MIN_CELL_N 이고 n_cid ≥ MIN_CELL_CID 입니다. 조건을 못 채운 셀은 2.8 의 계층 대체를 따릅니다.

### 2.2 신축/구축 보정 계수 f_age (구성 효과 제거)
```
# 추정 단위: 구×band (셀 수 부족하면 서울(적재된 구 전체)×band)
for each 셀 c in group:
    for cls in {N,S,R}:
        if n(c,cls)>=3 and n(c,'O')>=3:
            lr[c,cls] = ln(median ppm(c,cls) / median ppm(c,'O'));  w = min(n(c,cls), n(c,'O'))
f_age[cls] = exp(weighted_median(lr[.,cls], w))  if 사용 셀 수 >= 3 else 상위 그룹 값
f_age['O'] = 1.0 ;  f_age[None] = 1.0
# 층 보정 f_flr 도 같은 방식 (기준 'mid')
ppm_adj = ppm / (f_age[age_cls] * f_flr[flr_cls])     # "구축 16~29년, 중층" 환산 단가
```
- ppm_adj 는 할인율, 단순 중앙값 전년비, 기준 단가 비교에만 씁니다.
- 예상가는 원 단가 ppm 으로 계산합니다. 사용자가 받을 가격은 실제 섞여 있는 그대로이기 때문입니다.
- 30년 이상 구간은 서울에서 재건축 기대 때문에 f_age[R] > 1 이 나올 수 있습니다. 데이터가 정하게 두고, 미리 정한 값(prior)은 쓰지 않습니다.
- 선택 사항인 고급 대안은 고정효과 회귀입니다: ln ppm = α[동×band] + β[age_cls] + γ[flr_cls] + δ[ym] + ε. 반복 평균제거(alternating projections)로 풀면 numpy 만으로 됩니다. MVP 는 위의 비율법으로 충분합니다.

### 2.3 전년 동기 대비 변화율
방법 A (단순 중앙값, 연식 보정):
```
yoy_A = median(ppm_adj | V_P1) / median(ppm_adj | V_P0) - 1
조건: n_P1 >= 8 and n_P0 >= 8
```
- 장점: 표본을 다 쓰고 계산이 단순합니다.
- 단점: 구성 편향이 있습니다. 신축 입주, 고가 단지 거래 쏠림, 평형 구성 변화가 그대로 가격 변화처럼 보입니다. 연식 보정으로 일부만 줄어듭니다.

방법 B (같은 단지·같은 평형 매칭):
```
units = {(cid, atype) : P0 와 P1 양쪽에 유효 거래 존재}  # atype ±1㎡ 허용
for u in units:
    lr_u = ln(median ppm(u,P1) / median ppm(u,P0));  w_u = min(n(u,P0), n(u,P1))
yoy_B = exp(weighted_median(lr_u, w_u)) - 1
조건: |units| >= 3 and Σn(u,P0)>=6 and Σn(u,P1)>=6
```
- 장점: 입지와 품질이 고정되므로 순수한 가격 변화에 가깝습니다(반복매매지수와 같은 발상).
- 단점: 표본이 줄고, 거래가 잦은 대단지 쪽으로 치우칩니다. 기간 안에 거래가 없는 단지는 빠지고, 신축은 P0 에 없어서 아예 들어오지 못합니다.

결합 규칙 (구현값):
```
if B 가능:  m=|units|; λ = m/(m+3)
            yoy = λ*yoy_B + (1-λ)*yoy_A  (A 불가하면 yoy_B);  method='matched'
elif A 가능: yoy = yoy_A; method='median_adj'
else:        yoy = None -> 2.8 계층 대체
yoy_shr = (n_eff*yoy + K*yoy_gu_band) / (n_eff + K),  n_eff = min(n_P0,n_P1)
```
보조 지표인 단기 모멘텀(잠정)은 방법 B 를 P1v(8~9월)와 10월+PN 사이에 적용합니다.
```
mom = 매칭 log 비율
조건: 단위 ≥ 3 (못 채우면 None, 가중치 재배분)
```
'잠정' 표시를 반드시 붙입니다.

### 2.4 거래량 변화 (해제 제외, 완결 월만)
```
n1 = |V_P1v|, n0 = |V_P0v|        # 2026-08~09 vs 2025-08~09
vol_chg = ln((n1 + 2) / (n0 + 2))  # +2 평활, 로그 비율 (표시: exp(vol_chg)-1)
조건: n0 >= 5, 아니면 구×band 값으로 대체
liquidity = |V_R의 완결월 거래| / 완결월 수 / max(n_cid,1)   # 단지당 월 거래, 환금성
```
구조 단절 주의: 2025-10 에는 10·15 대책(서울 전역 토지거래허가구역 지정, 10/20 시행)이 있었다고 알고 있습니다. 직전 몰림 거래와 이후 급감이 기준기간에 섞여 있을 수 있습니다. 날짜와 범위는 제 지식 기준이라 확인이 필요합니다. 10월을 기준에서 빼는 것도 이 때문입니다.

### 2.5 구 평균 대비 할인율 (같은 band, 연식·층 보정 단가)
```
gu_ref = median(ppm_adj | 구 전체, 같은 band, 기간 R)
disc   = 1 - median(ppm_adj | 셀, R) / gu_ref     # +면 구 평균보다 저렴
disc_shr = (n_R*disc + K*0) / (n_R + K)           # 표본이 적으면 0(구 평균) 쪽으로
```
면적대를 섞은 구 중앙값과 비교하면 안 됩니다. 작은 평형이 많은 동은 ㎡단가가 높게 나와서 할인율이 왜곡됩니다.

### 2.6 키 맞추기 여력 (투자형 보조, 휴리스틱)
```
catch_up = (yoy_gu_band - yoy_shr) * 1[disc_shr > 0]
```
구 전체는 오르는데 이 셀은 덜 올랐고 아직 싸다는 뜻입니다. '싸서 싼 것'(입지 열위)일 수 있다는 경고를 함께 붙입니다.

### 2.7 해제·직거래 비율 (2026 같은 해 안에서만 비교)
```
cancel_rate = (c + α*p_gu) / (N_all + α),   c = 셀 2026(P1∪PN) 해제 행 수
              N_all = 같은 기간 (유효+해제) 행 수, p_gu = 구×band 해제율, α=10
direct_rate = (d + α*q_gu) / (n_R + α),     d = 셀 R 유효 거래 중 직거래 수
age_med     = median(age | V_R)  -> 신축도 점수에 사용 (낮을수록 높음)
```

### 2.8 계층 대체 (표본이 부족할 때)
```
order = [(구,동,band), (구,동,ALL band: ppm_adj 기준), (구,band), (서울,band)]
값은 처음 조건 충족 계층을 쓰되 level 을 기록하고, level>0 이면 등급 최대 C, level>=2 면 D
```

## 3. 점수 (0~100)

### 3.1 정규화
```
U = 등급 C 이상 셀 중 같은 band (|U|<10 이면 band 무시하고 전체 셀)
s(x) = 100 * (rank_below(x) + 0.5*rank_equal(x)) / |U|     # 기존 percentile_rank 그대로
'낮을수록 좋음' 지표는 s = 100 - s
None 은 점수 계산에서 빼고 가중치를 재배분: Score = Σ w_i s_i / Σ w_i(available)
Σ w_i(available) < 0.70 이면 점수 없음('지표 부족')
```
- 순위에는 수축값(_shr)을 넣습니다. 그래야 표본이 적은 셀이 극단 순위를 받지 않습니다.
- 비교군 U 는 불러온 구 범위에 따라 달라집니다. 화면에 "비교군: ○○구 등 N개 구, M개 셀" 을 반드시 표시합니다.

### 4.1 예상 매매가
```
rep_area = median(area | V_R) if n_R>=5 else median(area | V_P0∪V_R) else REP_AREA[band]
price_mid = ppm_med * rep_area ; price_lo = ppm_p25 * rep_area ; price_hi = ppm_p75 * rep_area
표시: 100만원 단위 반올림 (만원 기준 round(x/100)*100), "약 X억 Y천만원 (p25~p75: … )"
```
- rep_area 기본값은 셀 실측 중앙값입니다. 고정 REP_AREA(49/84/114)는 대체값으로만 씁니다.
- 선택 사항인 시점 보정: R 안에서 8월 거래를 최신으로 올리려면 ppm × (구×band 월별 매칭지수 비율)을 곱합니다. MVP 는 하지 않고 "최근 4개월 혼합 시세"라고 표기합니다.

### 4.2 선정 로직
```
def candidates(budget, prefs):   # prefs: 구 목록, band 목록, profile('live'|'invest'), 신축선호 등
    pool = [c for c in cells if c.grade in 'ABC' and c.band in prefs.bands and c.gu in prefs.gus]
    for c in pool:
        if c.price_lo > budget: drop                          # p25도 예산 초과
        u = c.price_mid / budget
        c.fit_label = '예산 내' if c.price_mid <= budget else '예산 경계(p25 이하 매물 위주)'
        c.budget_fit = (100 if 0.85<=u<=1.0 else
                        60 + 40*(u-0.6)/0.25 if 0.6<=u<0.85 else
                        50 if u<0.6 else
                        max(0, 100 - 200*(u-1.0)))
        c.score = weighted_score(c, profile)
    ranked = sort(pool, key=rank_score desc, tie=n_R desc)
    # 다양성: 같은 구 최대 3개, 같은 동 최대 1개(band 다른 것은 차순위)
    return top_k(ranked, k=10, diversity)
```
출력 필드:
- 구, 법정동, 면적대, 대표면적, 예상가와 범위, 점수, 상위 근거 지표 3개(문장), 신뢰등급, 표본수(n_R, 단지 수), 경고 목록
- cid, 건물명, 지번은 넣지 않습니다.
