## 0. 전제와 제약 (구현 전에 확인)
- **런타임 외부 호출 0건.** 서버는 로컬 `data/trades`와 `mydata/pseudo`만 읽는다. 실거래 갱신은 지금처럼 MCP `search_trades` → `tools/ingest.py`로 오프라인에서만 한다. 서버 코드와 HTML에는 API 키, 외부 URL, CDN, 웹폰트를 넣지 않는다. 시스템 폰트만 쓴다.
- 서버는 `http.server.ThreadingHTTPServer`로 만들고 `127.0.0.1`에만 바인딩한다. 응답 헤더: `Content-Security-Policy: default-src 'self'; style-src 'self' 'unsafe-inline'; script-src 'self' 'unsafe-inline'; connect-src 'self'`.
- **마이데이터는 `pseudo/`만 쓴다** (`raw/`는 읽지 않는다). 화면과 API에는 `customer_id`, 나이, 지역, 소득구간만 낸다. `name`, `rrn`, `mobile`, `account_no`, `account_id`는 응답에 넣지 않는다.
- **단위가 다르다.** 마이데이터는 **원**, 실거래(`THING_AMT`)는 **만원**이다. 서버 내부는 전부 **만원 정수**로 통일한다. 원 값은 수집 시 `// 10000`으로 바꾼다.
- **실거래 노출 범위**는 구, 법정동, 면적대, 집계값까지다. `cid`, 층, 계약일, 개별 거래행, 본번·부번·건물명은 어떤 응답에도 넣지 않는다. 추가 규칙: 셀(동×면적대) 안의 서로 다른 단지 수가 2 미만이면 시세를 공개하지 않는다. 단지 하나뿐인 셀은 가격 범위만으로 단지가 특정되기 때문이다. 단지 수는 서버 내부에서만 계산하고 응답에는 `suppressed_reason`만 낸다. 이 규칙은 `market.py`에 아직 없어서 `aggregate()`에 `n_cid` 계산을 추가해야 한다.
- **데이터 커버리지 공백 (현재 파일 기준).**
  - 종로구: 202508~10 파일만 있다. 최근 구간이 없어 "최근 데이터 없음"으로 표시한다.
  - 용산구: 202508~10과 202611만 있다. 최근 구간 202608~10이 없어 전년비를 낼 수 없다. 최신 시세는 잠정분만으로 계산된다.
  - 나머지 23개 구: 7개월 파일이 모두 있다.
  - 화면은 이 공백을 오류가 아니라 상태로 보여 줘야 한다 (6절).

## 1. 페이지 구성 (단일 HTML, 탭 2개: [내 집 찾기] [시장 개요])

### 1.1 헤더 (고정)
- 서비스명 옆에 데이터 기준일 배지를 둔다. 예: `실거래 2025.08~2026.11 계약분 · 2026.11은 잠정 · 수집일 2026-11-17`. 값은 `/api/meta`에서 받는다.
- 면책 문구 한 줄과 [자세히] 토글을 둔다. 문구: "가명 데이터로 만든 모의 계산입니다. 실제 대출한도와 세금은 금융회사 심사와 정책에 따라 다릅니다. 점수는 과거 거래 지표를 요약한 것이며 가격 예측이 아닙니다." 토글을 펼치면 정책 파라미터 기준일, 이상거래 제외 기준, 표본 기준(n≥5, 단지≥2)을 보여 준다.

### 1.2 1단계: 고객 선택과 재무 요약 카드
- 고객 선택: `<input list>` 자동완성(C0001~C1000)과 [무작위] 버튼.
- 요약 카드 4장. 각 카드에 출처 표기를 작게 붙인다. 예: "출처: 예금 3계좌, 증권 1건".
  1. **가용 자기자본** = 예금 합계 + 증권 평가액×0.9 − 비상자금(월 카드지출 평균×6). 연금은 넣지 않는다(본문에 "연금 제외" 표기).
  2. **연소득 추정** = 최근 12개월 `bank_transactions`의 `tx_type=IN`이고 `description=급여`인 거래 합계. 급여 기록이 없으면 `income_band` 중앙값 표(설정 파일)로 대체하고 "추정" 배지를 붙인다.
  3. **기존 부채**: 유형별 잔액과 연 원리금 상환액. DSR 산정 가정은 이렇다.
     - 주담대: 잔액·금리로 30년 원리금균등 상환
     - 신용대출: 잔액÷5년 + 이자
     - 자동차대출: 잔액÷3년 + 이자
     - 전세자금대출: 이자만
  4. **현재 DSR**: 원형 게이지(SVG)로 표시하고 기준선 40%를 함께 그린다.
- 빈 상태: 고객을 아직 고르지 않았으면 카드 자리에 "고객을 선택하면 재무 요약이 표시됩니다"를 보여 준다. 계좌가 0건이면 "예금 정보 없음, 자기자본 0으로 계산"이라고 쓴다.

### 1.3 2단계: 조건 입력 (`<form>`, 값이 바뀌면 300ms 디바운스 후 재계산)
- 목적: 라디오 [실거주 | 투자]. 투자를 고르면 경고를 띄운다. 문구: "서울 토지거래허가구역 안에서는 실거주 의무가 있어 전세를 끼고 사는 방식이 제한됩니다." 규제 반영 여부는 `policy.json`의 `toheo_all_seoul` 값을 따른다.
- 주택보유상태: 라디오 [무주택 | 생애최초(무주택 중) | 1주택(처분조건) | 다주택]. 기본값은 대출 내역으로 추정한다. 주담대가 있으면 1주택으로 두되 사용자가 바꿀 수 있다.
- 선호 구: 체크박스 25개와 [전체] [선택 해제] 버튼. 히트맵 셀을 클릭해도 토글된다.
- 면적대: 체크박스 [S 60㎡ 미만 | M 60~85㎡ | L 85㎡ 초과]. 각각 대표면적 49, 84, 114㎡를 옆에 표기한다.
- 금리 가정 슬라이더: `<input type=range>`, 3.0~7.0%, 0.1 단위, 기본 4.0%.
  - 슬라이더 옆에 "DSR 산정 금리 = 가정 금리 + 스트레스 가산 X%p" 계산식을 실시간으로 보여 준다.
  - 상환기간 셀렉트: 30년 또는 40년.
- 부대비용 체크박스 "취득세·중개보수 반영"(기본 ON).

### 1.4 3단계: 예산 산출 근거
- 핵심 숫자: **구입 가능 예산 최대 N억 N,NNN만원** = 자기자본 + 대출한도.
- 가로 막대 비교(SVG)로 세 한도를 나란히 그린다: LTV 한도, DSR 한도, 가격구간별 한도. 가장 작은 막대(묶인 한도)는 진한 색과 "적용" 배지로 표시하고 나머지는 연한 색으로 둔다.
- 한 줄 설명 예시: "DSR 한도가 가장 낮아 대출은 3억 1,200만원까지 가능합니다. 금리를 1%p 낮추면 +2,300만원." 민감도 수치는 서버가 함께 준다.
- 산식 펼침(`<details>`)에 단계별 값을 표로 보여 준다: 자기자본 → 부대비용 차감 → 가격 P에서의 각 한도 → 최종 P.
- 가격 P 계산:
  - 대출한도가 P에 따라 달라지므로(LTV×P, 가격구간 한도) 이분탐색으로 최대 P를 찾는다. 조건: `P + 부대비용(P) ≤ 자기자본 + min(LTV(P), DSR한도, 구간한도(P))`.
  - 결과의 `binding` 값은 `ltv | dsr | price_cap | equity | none_loan` 중 하나다. `none_loan`은 다주택 등으로 LTV가 0인 경우다.
- 정책 수치는 코드에 박지 않고 `policy.json`(기준일 포함)에 둔다. 초기값은 2025.10.15 대책 이후 서울 전역 규제지역 기준이며, 적용 전에 다시 확인해야 한다.
  - LTV: 무주택 40%, 생애최초 70%, 1주택(처분조건) 40%, 다주택 0%
  - DSR: 40%
  - 수도권 스트레스 가산: 3.0%p
  - 가격구간 한도: 15억 이하 6억, 15억 초과~25억 4억, 25억 초과 2억
  - 취득세: 간이 1~3% 구간표
  - 중개보수: 0.5%

### 1.5 4단계: 추천 리스트
- 후보 조건: 선호 구와 면적대에 해당하는 셀 가운데 `price_p25 ≤ 예산`인 것.
- 정렬: 기본은 점수 내림차순이고, 예상가 낮은순과 표본 많은순으로도 바꿀 수 있다.
- 각 항목은 `<li>` 카드로 만든다.
  - 제목: `마포구 ○○동 · 60~85㎡`. 법정동명까지만 쓴다.
  - **상승 여력 점수 0~100**: 큰 숫자와 등급 글자(A/B/C)를 함께 쓴다. 색만으로 구분하지 않는다.
  - **예상가 범위**: `9억 1,000만 ~ 10억 4,000만원 (대표면적 84㎡, 중앙 9억 7,500만)`. 예산 대비 위치는 미니 막대로 그리고, p25·중앙·p75와 예산선을 표시한다.
  - 지표 배지 최대 4개. 각 배지는 텍스트와 화살표 기호로 쓴다.
    - 전년비: `전년비 +6.2% (같은 단지 비교)` 또는 `(중앙값 비교)`
    - 거래량 변화: `거래량 +35%`
    - 구 대비 수준: `구 평균 대비 −12%` (점수 산식에서는 저평가로 본다)
    - 건축연한: `중위 연식 18년`
  - 표본수: `거래 23건 (잠정 4건 포함)`. 15건 미만이면 "표본 적음" 배지를 붙인다(6절 참조).
  - 근거(`<details>`): 점수 구성요소별 백분위와 가중치 표, 그리고 텍스트 한 줄. 예: "같은 구 셀 중 전년비 상위 20%, 거래량 회복 상위 35%".
- 점수 산식. 서버가 계산하고 가중치는 `policy.json`에 둔다. 가중합을 0~100으로 표시한다.
  - 기준 집단: 같은 면적대의 서울 전체 공개 셀
  - 구성요소와 가중치:
    - 전년비 백분위 35%
    - 거래량 변화 백분위 20%
    - 구 대비 저평가 정도 20% (`−rel_gu`의 백분위)
    - 연식 15% (낮을수록 높게)
    - 표본 신뢰도 10% (`min(n/30, 1)`)
  - 값이 없는 지표(`null`)는 가중치를 나머지에 비례 배분하고 "지표 일부 없음"을 표기한다.
  - `yoy_method=median`이면 전년비 가중치를 절반으로 줄인다. 단지 구성 변화로 생기는 편향 때문이다.
- 상위 3개는 카드 위에 하이라이트로 고정한다. 나머지는 20개씩 [더 보기]로 연다.

### 1.6 25개 구 히트맵 그리드 (두 탭 공용 컴포넌트)
- CSS grid 7열×5행으로 만든 근사 타일 배치다. 지리 정확도는 보장하지 않으며 화면에 "근사 배치"라고 쓴다. 좌표는 (행,열)이다.
  - 0행: 은평(0,1) 강북(0,3) 도봉(0,4) 노원(0,5)
  - 1행: 서대문(1,1) 종로(1,2) 성북(1,3) 동대문(1,4) 중랑(1,5)
  - 2행: 강서(2,0) 마포(2,1) 중구(2,2) 성동(2,3) 광진(2,4) 강동(2,5)
  - 3행: 양천(3,0) 영등포(3,1) 용산(3,2) 서초(3,3) 강남(3,4) 송파(3,5)
  - 4행: 구로(4,0) 금천(4,1) 동작(4,2) 관악(4,3)
- 지표 셀렉트: [㎡단가 | 전년비 | 거래량 변화 | 예산 내 후보 수(내 집 찾기 탭 전용)].
  - 순차 지표(단가, 후보 수)는 단색 명도 5단계로 칠한다.
  - 증감 지표(전년비, 거래량)는 0을 중심으로 한 발산형 2색으로 칠한다.
- 각 타일 표시: 구 이름, 값 텍스트(예: `+4.1%`), 상태 기호.
  - 데이터 없음: 빗금 패턴과 "—"
  - 잠정 포함: "잠정" 위첨자
  - 표본 부족: "표본↓"
- 하단에 범례를 둔다(구간 경계값 텍스트 포함).
- 타일은 `<button aria-pressed>`이고, 누르면 선호 구 선택이 토글된다.

### 1.7 시장 개요 탭
- 위에 히트맵을 두고, 아래에 구별 표를 둔다. 열 머리를 눌러 정렬할 수 있다.
- 표 열: 구, 최근 ㎡단가 중앙(만원, 괄호에 3.3㎡당 환산), 전년 동기 ㎡단가, 전년비, 최근/전년 거래 건수, 거래량 변화, 상태.
- 구를 고르면 패널이 열린다.
  - 동×면적대 셀 표: 공개 셀만 보여 주고, 비공개 셀 수는 "비공개 n개(표본 부족·단일 단지)"로만 쓴다.
  - 월별 ㎡단가 중앙값 선 차트(SVG): 7개 월 지점을 찍고, 202611은 점선과 빈 점으로 그린다.
- 기간 정의를 고정 문구로 적는다. "최근 = 2026.08~10, 전년 = 2025.08~10 (같은 달끼리 비교), 2026.11 = 잠정 (최신 시세에만 반영하고 전년비에는 넣지 않음)".

### 1.8 이상거래 제외 내역 (시장 개요 탭 하단 섹션, 내 집 찾기 탭에서는 링크)
- 사유별 건수 표: 해제(취소) 신고, 면적·금액 누락, 동일 거래 중복 행, 직거래 저가(동 중앙값 70% 미만). 비율도 함께 쓴다(전체 원천 행 대비).
- 구별 제외 건수 막대(SVG)와 기준 설명을 붙인다.
- 개별 제외 거래 목록은 내보내지 않는다. 구×사유 집계만 보여 준다.
- 수집 경고: 원천 1,000건 상한에 닿은 파일이 있으면 "일부 월 데이터가 잘렸을 수 있음: 구_월 목록"을 표시한다. 이를 위해 ingest가 남기는 `hit_cap_1000` 값을 메타 파일로 저장해야 한다.

## 2. API (모두 GET 또는 POST JSON, UTF-8, 금액 단위는 만원 정수)
- 공통 오류 형식: `{"error":{"code":"NOT_FOUND|BAD_REQUEST|NO_DATA","message":"한국어 메시지"}}`

## 3. 빈 상태, 표본 부족, 잠정 데이터 표기 규칙
| 상황 | 판정 | 표기 |
|---|---|---|
| 고객 미선택 | 클라이언트 | 2~4단계 비활성, 안내 문구 |
| 예산 0 이하 | `budget_max ≤ 0` | "현재 조건으로는 구입 가능 예산이 없습니다" + 가장 큰 제약 요인 |
| 선택 범위에 셀 없음 | `no_cells_in_selection` | "선택한 구·면적대에 공개 가능한 시세가 없습니다", [면적대 넓히기] 버튼 |
| 모두 예산 초과 | `all_over_budget` | 가장 가까운 후보 1개와 "N,NNN만원 부족" |
| 셀 비공개 | n<5 또는 단지<2 | 목록에 넣지 않고 집계 수만 표시 |
| 표본 적음 | 5≤n<15 | "표본 적음" 배지, 점수 옆 "신뢰도 낮음" |
| 잠정 포함 | n_prov>0 | "잠정 n건 포함" 텍스트, 차트에서 점선 |
| 잠정만 있음 | n_recent=0 (용산구 등) | 시세는 "잠정 기준"으로 표시, 전년비 "산출 불가" |
| 최근 데이터 없음 | 종로구 | 히트맵 빗금, 표에 "최근 데이터 없음" |
| 지표 null | yoy·vol_chg 없음 | 배지를 생략하고 근거에 "자료 부족으로 제외, 가중치 재배분" |
| 서버 오류 | fetch 실패 | 해당 섹션에만 `role=alert` 메시지와 [다시 시도] |

## 4. 한국어 숫자 표기 (`fmt.js` 역할의 인라인 함수, 서버도 같은 규칙)
- `fmtManwon(v)`는 만원 정수를 받는다.
  - 1억 이상: `X억 Y,YYY만원`. Y가 0이면 `X억원`. 예: `97500` → `9억 7,500만원`.
  - 1억 미만: `Y,YYY만원`.
  - 목록과 배지에서는 반올림 축약을 쓴다. 예: `9.8억`.
- ㎡단가: `㎡당 2,850만원`. 보조로 `(3.3㎡당 9,422만원)`를 붙이고, 계수 3.3058은 표기에 명시한다.
- 비율: 부호를 항상 붙이고 소수 1자리로 쓴다(`+6.2%`, `−3.0%`). 음수 기호는 U+2212를 쓴다.
- 날짜: `2026.11`, 기준일은 `2026-11-17`.
- 스크린리더용 `aria-label`에는 축약하지 않은 값을 넣는다. 예: "9억 7천5백만 원".

## 5. 접근성
- 단계별 `<section aria-labelledby>`, 랜드마크(`header`, `main`, `nav`(탭)), 탭은 `role=tablist` 패턴과 화살표 키 이동.
- 재계산 결과는 `aria-live=polite` 영역에서 알린다. 예: "예산 7억 8,400만원, DSR 한도 적용, 후보 37곳".
- 색만으로 정보를 전달하지 않는다. 증감은 기호(▲▼)와 텍스트로도 나타내고, 히트맵 타일에도 값 텍스트를 쓴다. 대비는 4.5:1 이상으로 한다.
- 모든 SVG에 `role=img`, `<title>`, `<desc>`를 붙이고, 같은 데이터를 담은 숨김 `<table>`(`.sr-only`)을 제공한다.
- 포커스 링을 유지하고, 슬라이더에는 `aria-valuetext="연 4.0%"`를 준다. `prefers-reduced-motion`이면 전환 효과를 끈다.

## 6. 인라인 SVG 차트 최소 구성 (공용 함수 3개 + 게이지)
1. `barCompare(limits, binding)`: 3단계 한도 비교용 가로 막대 3개. 값 라벨과 "적용" 배지를 그린다.
2. `rangeBar(p25, med, p75, budget)`: 추천 카드 예상가 범위 미니 막대(높이 16px). 예산 세로선을 그린다.
3. `lineMonthly(points)`: 시장 개요 월별 ㎡단가 선 차트. 7개 점, y축 눈금 3개, 잠정 구간은 점선이다.
4. `gauge(dsr, cap)`: 1단계 DSR 반원 게이지와 40% 기준선.
- viewBox 기반으로 반응형으로 그린다. 색은 CSS 변수 4개(주색, 연한 주색, 증가, 감소)만 쓰고 라이트·다크 둘 다 지원한다. 애니메이션은 넣지 않는다.
