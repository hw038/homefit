# HomeFit 서울 (MVP)

가명 마이데이터 고객의 자산·부채·소득으로 서울 아파트 구입 가능 예산을 계산하고, 서울 실거래(법정동×면적대 통계)로 예산 안의 후보와 상승 여력·가치 점수를 보여 주는 웹 MVP.

## 실행
```
cd ~/claude-lab/capstone/homefit
python3 -I server.py --port 8765        # 127.0.0.1 에만 바인딩
```
VS Code(code-server) 포트 프록시로 열 때는 주소가 `…/proxy/8765/` 로 끝나야 한다(페이지가 자동으로 / 를 붙임). 또는 SSH 포트 포워딩: `ssh -L 8765:127.0.0.1:8765 ec2-user@<EC2 주소>` 후 브라우저에서 localhost:8765 접속.

테스트: `python3 -I tests/test_app.py` (네트워크 없이 핸들러를 메모리에서 구동, 33개)

## 구성
| 파일 | 역할 |
|---|---|
| server.py | http.server API + index.html 서빙, 입력 검증, 응답 금지키 검사 |
| budget.py | 고객 프로필(연소득=급여 입금, 자기자본, 부채 원리금) · 예산(min(LTV, DSR, 가격구간 상한), 부대비용) |
| market.py | 정제(해제·중복·직거래 저가·극단값) · 연식/층 보정 · 같은 단지 매칭 전년비 · 수축 · 점수 · 추천 |
| policy.json | 대출·세금 규칙과 점수 가중치 (2025.10.15 대책 기준, 확인 필요) |
| static/index.html | 단일 페이지 UI (외부 CDN 없음) |
| tools/ingest.py | search_trades 결과 → 본번·부번·건물명 삭제 후 data/trades 저장 |
| tools/compare.py | 독립 전사본 일치 검증 |
| docs/research/ | 규제·고객데이터·방법론·UX 조사 보고서 |

## 데이터 갱신
seoul-realestate MCP `search_trades(gu, YYYYMM, limit=1000)` 호출 → 결과 파일 경로로 `python3 -I tools/ingest.py <구> <YYYYMM> <경로>`. 키는 MCP 등록에만 있고 이 앱은 런타임에 외부를 호출하지 않는다.

## 알려진 한계
- 규제 수치는 지식 기준(2026-06)이며 웹 검색으로 재확인하지 못함. 토지거래허가구역 2026.12.31 만료 예정.
- 합성 고객 데이터라 자산 규모가 작아 추가 자금 없이 후보가 거의 없음 → 추가 자금/전세 순반환/목표 계획 기능 제공.
- 비식별 데이터에 동·호가 없어 '같은 집 반복거래' 규칙은 적용하지 않음.
- 1,000건 상한에 닿은 파일: 강동구_202509, 동대문구_202510 (일부 누락 가능).
- 2026.10~11 계약분은 신고 기한 중(잠정). 12월 이후 재수집 권장.
